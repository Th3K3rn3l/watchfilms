# ⚡ Yandex Cloud Functions — Бэкенд и Сигнальный сервер P2P для WatchFilms

Этот серверный скрипт обеспечивает **прямое P2P соединение (WebRTC)** между вами и другом:
- **Blazing Fast**: фильм передаётся напрямую от хоста к другу по UDP через NAT (STUN hole-punching). Никаких промежуточных серверов или туннелей, скорость ограничена только вашим провайдером.
- **Бесплатно навсегда**: видеопоток **не проходит** через облако — через Яндекс передаётся только начальный SDP-хэндшейк (~1 КБ). Это укладывается в бесплатный лимит Yandex Cloud (1 млн вызовов в месяц).
- **Другу не нужно ничего скачивать и настраивать**: функция сама отдаёт интерфейс просмотра и Service Worker в браузер.

---

## 🚀 Быстрый запуск за 2 минуты

### 1. Создать функцию в консоли Yandex Cloud

1. Откройте [Консоль Yandex Cloud](https://console.yandex.cloud/) → **Cloud Functions** → нажмите **«Создать функцию»**.
2. Введите имя: например, `watchfilms-p2p`.
3. Среда выполнения: **Node.js 18** (или 20 / 22).
4. Способ редактирования: **Редактор кода**.
5. Точка входа: `index.handler`.
6. Скопируйте всё содержимое файла `yandex/index.js` из этого репозитория и вставьте в редактор файла `index.js`.
7. Нажмите **«Сохранить изменения»**.

### 2. Сделать функцию публичной

1. На странице функции перейдите во вкладку **«Обзор»**.
2. Включите переключатель **«Публичная функция»** (чтобы друг мог открыть ссылку без авторизации в Яндексе).
3. Скопируйте ссылку на функцию из блока «Ссылка для вызова»:
   ```
   https://functions.yandexcloud.net/d4e1234567890abcdefg
   ```

## 🎬 Использование в WatchFilms

### Вариант 1: Через команду запуска

```bash
# Linux
./watchfilms -signal https://functions.yandexcloud.net/ВАШ_ID_ФУНКЦИИ

# Windows
watchfilms.exe -signal https://functions.yandexcloud.net/ВАШ_ID_ФУНКЦИИ
```

Или через переменную окружения:
```bash
export YCF_URL="https://functions.yandexcloud.net/ВАШ_ID_ФУНКЦИИ"
./watchfilms
```

### Вариант 2: Прямо в окне программы (без перезапуска)

1. Запустите `./watchfilms`.
2. Нажмите кнопку **«Пригласить»**.
3. В блоке **⚡ P2P (Yandex Cloud Functions)** вставьте ссылку на вашу функцию и нажмите **«Включить P2P»**.
4. Программа автоматически сохранит адрес и выдаст ссылку P2P для друга!
